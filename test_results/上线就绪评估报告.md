| 风险 | 等级 | 说明 |
|------|------|------|
| GitHub Pages 404 响应 | 🟢 低 | mock 拦截器已处理所有异常码（ERR_CONNECTION_RESET/ERR_NETWORK/ERR_BAD_RESPONSE/HTML_404），无影响 |
| localStorage 数据不一致 | 🟢 低 | 已通过 userId 隔离 + 问卷守卫解决，但如果浏览器清除 localStorage 会导致数据丢失（符合预期） |
| 管理员会话切换 | 🟡 中 | 自动化测试中，学生→管理员切换需清除全部 localStorage 才能正确触发；UI 层面通过"退出登录"可解决 |
| 浏览器兼容性 | 🟢 低 | 基于 Vue 3 + Element Plus，主流浏览器均支持 |
| 无后端数据持久化 | 🟡 中 | 所有数据仅在 localStorage，浏览器清除或更换设备即丢失 |
