# 新生宿舍匹配系统测试说明

## 测试入口

- 线上地址：https://sy25255.github.io/dorm-match/
- 学校编码：`DEMO-UNI`
- 推荐入口：进入学校后使用“填写测试信息进入”

## 测试目标

请按真实大一新生的视角使用系统，重点观察：

- 是否能顺利进入系统，不需要复杂注册。
- 问卷填写、暂存、提交是否顺畅。
- 匹配推荐是否容易理解。
- 邀请舍友、接受邀请、查看组队状态是否清楚。
- 宿舍分配结果、确认、异议/反馈入口是否好找。
- 页面在手机和电脑上是否存在文字溢出、按钮难点、加载空白等问题。

## 建议测试流程

1. 打开线上地址，输入学校编码 `DEMO-UNI`。
2. 使用“填写测试信息进入”，填写昵称、学院、专业。
3. 完成偏好问卷并提交。
4. 查看推荐舍友列表和匹配详情。
5. 尝试给一个同学发送邀请。
6. 使用另一个浏览器或无痕窗口再创建一个测试用户，接受邀请。
7. 查看组队状态、通知、个人资料、建议反馈。
8. 如果有宿舍分配结果，测试确认结果、宿舍群聊、提交异议。
